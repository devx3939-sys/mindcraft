🤖 Mindcraft Deployer

Deploy a utility bot to your Minecraft server

Quick Start

Configure your bot below and click Deploy to join a running Minecraft server.

Note: The server must be running and accepting connections.

Microsoft Authentication Help

If deploying to an Aternos or online-mode server you can either:

  • Paste an existing Microsoft access token into the field above (advanced).
  • Or run the viaproxy service and add/select a Microsoft account there (see services/viaproxy/README.md).

📋 Available Bot Commands

  • !leave - Disconnect from the server
  • !mine/collect <item> <quantity> - Mine or collect specified items
  • !speedrun - Attempt to beat the game quickly
  • !survive - Focus on survival and gathering resources
  • !protect <player/base> - Protect a player or your base
  • !pvp <player/all> - Engage in combat
  • !buildEmpire - Build a base with farms and diamond gear
  • !trade <action> - Trade with villagers
  • !farm <crop> - Set up and manage farms
  • !fish - Fish for items and food
  • !hunt <animal> - Hunt animals for food
  • !sleep - Find and sleep in a bed
  • !heal - Find food to restore health
  • !inventory - View current inventory
  • !stats - Display bot status and statistics
  • !goToPlayer <name> <distance> - Go to a specific player
  • !searchForBlock <block> <range> - Find and go to a block type
  • !collectBlocks <block> <quantity> - Collect specific blocks
  • !craftRecipe <item> <quantity> - Craft items
  • !attack <entity> - Attack a mob type

After deployment, go to the dashboard to manage your bots.
